# BankAccount

Console bank account application written in C++ with transaction history and file export.

## Features

- Deposit and withdraw money
- Balance validation (prevents overdraft)
- View transaction history
- Save history to file

## Technologies

- C++
- OOP (two classes: Account, Transaction)
- Enum types
- STL (vector)
- File I/O (fstream)
- Input validation

## How to run

1. Clone the repository
2. Open `BankAccount.cpp` in Visual Studio or any C++ compiler
3. Build and run
4. Transaction history is saved to `history.txt`
